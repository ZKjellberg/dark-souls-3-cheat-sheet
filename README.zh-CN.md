# 黑暗之魂 3 全收集清单

[Dark Souls 3 Cheat Sheet](https://github.com/ZKjellberg/dark-souls-3-cheat-sheet) 支持简体中文与英文，保留原有勾选进度格式。

中文覆盖本体、《艾雷德尔之烬》和《环印城》的全部 1,953 个清单条目，包括流程、成就、武器、盾牌、防具和鸟巢交换；导航、筛选、搜索、设置、档案弹窗、完成状态、确认提示和导入错误提示也支持中文。外部 Wiki 链接仍指向原攻略使用的英文页面。

## 使用

无需构建。安装 Node.js 后，在仓库目录运行：

```sh
node tests/server.cjs
```

访问 <http://127.0.0.1:8080/?lang=zh-CN> 查看中文版，或访问 <http://127.0.0.1:8080/?lang=en> 查看英文版。页面沿用上游固定版本的 CDN 资源，首次加载这些资源需要联网。

顶部“语言”选择框可以切换中英文；手机上先展开导航菜单。首次访问时按浏览器语言选择，明确指定的 `?lang=` 参数优先于已保存的偏好。切换语言会刷新页面，并保留当前档案、已完成项目、筛选条件、折叠状态、主题与当前标签页。

进度保存在当前网站地址对应的浏览器本地存储中。更换浏览器、域名或端口不会自动同步旧进度；请先在旧页面的“设置”中导出档案，再到新页面导入。语言偏好独立保存，不写入档案备份。建议在清除网站数据前导出备份。

## 维护翻译

- `js/locales/zh-CN.js`：`text` 保存界面翻译，`entries` 按 `data-id` 保存清单内容。
- `js/i18n.js`：选择语言，在清单与搜索初始化前应用翻译；缺少译文时显示英文原文。
- `js/main.js`：动态文字通过 `DS3I18n.t()` 翻译；用户自行输入的档案名称保留原文。

新增或修订内容时，保持 `data-id`、原始链接和嵌套清单不变，避免破坏进度兼容性。中文清单基于 [soarqin 的社区译稿](https://github.com/soarqin/dark-souls-3-cheat-sheet/blob/856c2cf62924a01cf27585b2f2d5c714cd473176/index.html) 整理，并修正了与最新上游不一致的条目、损坏链接和部分术语及说明。翻译来源及许可见 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 检查

Node.js 20 及以上版本可运行：

```sh
npm ci
npx playwright install chromium
npm test
```

检查涵盖 1,953 个条目的中文覆盖和链接兼容、语言选择与英文回退、中文搜索、档案及进度保留、导入导出、动态提示和手机导航。

使用已安装的 Chrome 时，在 PowerShell 中先设置 `$env:PLAYWRIGHT_CHANNEL = 'chrome'`。如果网络需要代理，可设置 `PLAYWRIGHT_PROXY` 为对应的 HTTP 代理地址。测试需要访问页面依赖的 CDN，并会禁用统计请求。
